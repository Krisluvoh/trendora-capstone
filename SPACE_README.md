# Trendora — Multi-Agent Sales Concierge

A three-agent sales concierge (Intake, Research, Recommendation) for
hype-cycle products — limited sneaker drops, boutique exclusives, viral
gadgets. Describe what you're after and get a reasoned recommendation, with
memory across turns so follow-up objections get handled in context.

Runs on Groq's free-tier API. Full source: see the GitHub repo linked from
this Space.
